# AI Switch for OTools v0.5.0

本次更新重整账号中间件，让插件的用途、执行位置和失败处理规则更清楚，并统一内置与第三方插件的宿主接口。

## 中间件与错误处理

- 原有零散失败策略整合为“失败重试”“流式恢复”“账号故障处理”三个独立插件，按实际生命周期分类。
- 只显示账号已添加的中间件；支持搜索添加、关闭、移除和展开配置。新账号默认添加常用恢复策略。
- 插件说明展示典型报错，例如 `stream disconnected before completion`、`invalid_encrypted_content`、Azure 跨资源历史引用错误，并说明适用条件。
- 错误规则支持 HTTP 状态、code/type、消息匹配、条件组合、排除条件、优先级与样例测试。关闭或移除插件后不再继承隐藏策略。

## 请求头与图片处理

- User-Agent 和自定义请求头统一进入“请求头设置”插件，支持补充、覆盖和移除。旧设置自动迁移。
- 远程图片下载内嵌和历史图片数量限制合并为“图片处理”，两个选项独立控制，可设置保留图片数。
- Brotli 功能明确命名为“请求体压缩”；它不改变图片分辨率或画质。
- 请求历史加密清理、跨资源状态清理等归入实际生效的请求阶段。

## 插件接口与可靠性

- 内置与第三方中间件共用版本化描述、生命周期、配置编辑器和宿主动作。提供可安装的外部账号故障处理示例及开发文档。
- 请求、响应、流事件、失败和完成事件采用统一调度；首次请求与续写共用处理链路。
- 账号动作在事务内处理，限制作用域并对重复事件去重；避免覆盖用户暂停/撤销状态。
- 修复双向重复执行、失败钩子因日志重复调用、插件冷却被内部结算覆盖等问题。
- 插件运行器独立隔离，加载与停用按版本发布；慢图片下载不会占住全局插件锁，下载地址与大小校验得到加强。
- 插件更新采用暂存、切换与失败恢复，不可用插件的历史配置可保留。

## 升级与验证

旧版中间件、请求头和图片配置会自动迁移，原参数保留。新增数据库迁移仅增加插件动作去重与独立状态表，不修改既有迁移内容。

发布前本地验证：Rust 2176 项通过（6 项需要真实环境的测试忽略），前端 943 项通过；TypeScript 和生产构建通过。发行工作流另外执行三平台原生构建、插件边界测试、隔离烟测、重启与本地模拟生图路由测试、包结构及 SHA-256 校验。

平台包：Windows x64、Linux x64、macOS ARM64。流式续写会发起新的上游请求，可能另行计费；仅在需要时启用。
