# AI Switch for OTools v0.1.6

## 实时路由可视化

- 账号池顶部工具栏和侧栏增加「实时路由」入口，展示 **Agent 客户端 → AI Switch 网关 → 账号池** 的调用关系。
- 真实上游请求按客户端颜色显示移动光点；空闲时保留淡色静态虚线，不用动画冒充流量。
- 右侧账号按当前并发排序，空闲账号补足到 **12 个**；实际不足时显示全部，活跃账号超过 12 个也不截断。
- 正确跟随请求结束、取消、重试和续写换号；停止网关时取消旧请求，避免已停止的连接重新出现在图中。
- 增加「模拟流量／停止模拟」。模拟只在页面本地演示，不发送真实上游请求、不写日志或用量、不产生费用；停止后立即恢复最新真实状态。
- 可视化只读取脱敏账号摘要和成员 ID，不加载账号凭据、配置或请求历史。

## 客户端来源识别

- 写入客户端配置时，网关 Key 自动添加客户端后缀，例如 `.zcode`、`.workbuddy`、`.codex`，请求日志和用量详情记录客户端来源。
- 已有无后缀 Key 继续有效，来源显示为「未识别客户端」。主动重新写入一次客户端配置即可启用识别，不自动覆盖已有配置。
- 后缀是调用方声明的来源标签，**不是独立权限、可撤销的客户端 Key 或更强的身份认证**。数据库中的基础 Key 与轮换别名保持不变；未知后缀不能通过认证。

## 界面与账号设置

- 客户端接入页「写入」按钮和提示整行固定在底部，列表和手动参数区域单独滚动；不遮挡最后一项，窄窗口也保持可见。
- 可视化移除上方统计卡片，计数与真实网关状态保留在图中。
- 账号列表默认隐藏来源标记；需要显示时，可在刷新下拉的「显示内容自定义」中开启「账号来源」。
- 「容量不足／高负载」的一键重试预设调整为 **100 次／500 毫秒**。这是快捷预设，不会自动改写账号已保存的重试策略。

## 图标与兼容

- 离线随包提供 DeepSeek Harness、DeepSeek Harness Desktop 和 Hermes Agent 的官方项目图标及许可声明，客户端接入页和可视化共用图标。
- 其它已有平台图标继续使用；尚未取得明确再分发许可的厂商品牌保留字标回退，不声称所有图标均为官方。
- 本地 AI 默认地址仍为 `http://127.0.0.1:29527`，管理命令不暴露在模型端口。更新不会迁移或覆盖独立版数据目录。
