# AI Switch for OTools v0.1.7

## 单屏紧凑实时路由

- 实时路由改为紧凑三栏监控台：**Agent 客户端 → AI Switch 网关 → 账号池**。
- 在 **900×600** 窗口、默认侧栏展开时，可同屏显示 **15 个客户端、12 条账号和网关**，主图无需横向或纵向滚动。
- 顶部压成单行，网关和节点缩小，说明与错误详情移入弹窗，避免占用可视化高度。
- 更小的窗口按实际空间减少主图可见行数，更多节点通过 **「＋N」** 查看。完整数据保留，额外活跃项明确标数，不静默丢弃请求。
- 点击客户端或账号可高亮真实调用关系；从完整列表选择隐藏节点，可将其定位到主图。再次点击、清除或按 Escape 取消高亮。
- 保留按并发排序、空闲静态虚线和客户端颜色光点；真实流量与本地模拟继续独立，模拟不发送上游请求或产生用量。

## 正确的官方客户端图标

- 修正 WorkBuddy／WorkBuddy AI 仍使用 W 占位标的问题，改为官方绿色 Buddy 图标。
- CodeBuddy CLI 改为官方紫色 Buddy 图标；ZCode、Qoder CLI／Qoder CN CLI 改为核对过的官方原始图标，不再使用字母占位。
- 客户端接入页与实时路由共用离线图标，不在运行时请求外部图标服务。保留来源、原始文件校验和以及相关第三方声明，不表示官方合作或背书。

## 动态显示与可访问性修复

- 修正额外活跃项提示出现／消失后连线端点可能偏移的问题；窗口缩放、侧栏调整和节点重排时同步更新真实锚点。
- 修正已消失账号再次出现时意外恢复旧高亮选择的问题。
- 完整列表、说明和错误弹窗支持键盘 Tab、Escape、关闭后焦点恢复，避免被主图裁切。
- 保留系统减少动画偏好；减少动画时不显示运动光点，静态连接和计数仍可查看。

本次更新不改变账号路由策略、客户端 Key 鉴权规则或数据库结构。本地 AI 默认端口仍为 29527，已有客户端配置与账号数据无需迁移。
