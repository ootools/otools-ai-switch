AI Switch 的首个 OTools 独立插件版本。本次安装包适用于 **Windows x64**。

- 默认以 Panel 打开，通过 OTools SDK 接入宿主。
- 提供账号池、模型映射与路由、JSON/SSE 转发、用量统计、生图、MCP、Skills 及会话浏览。
- AI 接口默认监听 `127.0.0.1:10888`，使用本地 API Key；数据独立保存在 `~/.otools/local/otools-ai-switch/ai-switch.db`。
- 不包含 Vibe 终端、自建管理 Web 服务、Tailscale 或原版插件机制。
- 移除左侧“客户端接入”入口，重做向量图标，账号列表填满剩余空间。
- 适配远程宿主文件选择、Panel 关闭订阅清理、原生插件停机与导出路径。

安装：在 OTools 插件管理中选择“本地安装”，导入 `otools-ai-switch-0.1.0.oplg`。

校验：使用附带的 `SHA256SUMS` 验证下载文件。

验证：前端完整测试 814 项通过，最后布局相关回归 296 项通过；Rust 完整测试 1938 项单元测试与 4 项插件边界测试通过（6 项真实账号/环境测试忽略），最后导出回归 26 项通过。最终 Windows release 库已通过隔离数据库、鉴权、模型映射、JSON/SSE 与活动流式请求停机测试。

本次未发布 macOS/Linux 安装包，未使用真实账号执行 OAuth 或付费上游生成；实际 OTools 桌面安装和远程宿主环境尚未做端到端验收。
