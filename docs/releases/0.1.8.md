# AI Switch for OTools v0.1.8

## 账号批量选择更直观

- 移除账号列表表头的全选复选框，保留每个账号的选择框。
- 在原有账号操作条中，按 **「全选｜反选｜取消选择」** 顺序排列按钮；列表模式与卡片模式一致。
- 保留原显示机制：**至少勾选一个账号才显示操作条**；点击取消选择、取消最后一个勾选或反选后无已选账号时，操作条立即关闭。
- 全选仅补齐当前页筛选结果，重复点击不会取消已选；反选仅翻转当前页账号，保留其它页的选择；取消选择清空所有已选账号。
- 页面正在加载、切换页的占位数据、加载失败或没有账号时，不允许对不确定的页面数据执行全选／反选。

批量设置状态、移动到分组、删除确认以及筛选／翻页的既有行为保持不变。本次不修改账号路由、客户端 Key 鉴权规则或数据库结构。
