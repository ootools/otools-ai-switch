AI Switch · AI本地网关 `v0.1.1`。本次发布安装包适用于 **Windows x64**。

## 新增与修复

- 图片账号支持独立的 **Nano Banana**（`gemini-2.5-flash-image`）与 **Nano Banana Pro**（`gemini-3-pro-image-preview`）预设，新增、编辑及上游端点自动填充；修复相同 Google Base URL 导致 Pro 被误识别为初代的问题。
- 图片账号改用生图专用表单，提供 OpenAI / GPT Image、Google Gemini 图片和豆包 Seedream 预设，自动保存 `image.generate` 能力。
- 修复 Seedream `/api/v3` 图片路径重复拼接 `/v1`、图片请求参数差异和 GPT Image 的 `response_format` 不兼容；支持安全读取 URL 图片结果并保存资产。
- 图片、视频、音频 TAB 统一显示对应端点和共享 Key，移除图片页“跳转生图”。压缩、内容过滤、推理和工具兼容配置仅在通用 TAB 显示，媒体表单保留已有隐藏设置。
- 算力池占满整行：中间为服务操作，最右侧为列表/卡片切换、添加和刷新；筛选条件右对齐，provider 超宽时自动收到“更多”。
- 默认中文，保留已选择的语言；显示名更新为 **AI Switch · AI本地网关**。恢复原版 Logo，窗口尺寸使用 OTools 默认或记忆值。
- 接入 OTools 桌面插件后台启动任务，重启宿主后无需打开 Panel 就会启动 AI 服务。账号读取和服务启停失败显示具体错误、诊断详情和重试。

## 安装与数据

在 OTools 插件管理中安装/更新 `otools-ai-switch-0.1.1.oplg`。请使用附带的 `SHA256SUMS` 校验下载文件。

AI 接口默认 `http://127.0.0.1:10888`，需本地 API Key。数据库仍保存在 `~/.otools/local/otools-ai-switch/ai-switch.db`，更新不改存储目录或历史 SQL 迁移。首次安装后的即时启动可使用页面开关；重启桌面宿主后由后台任务启动。纯 CLI 自动启动未包含在本次实现中。

## 验证范围

发布前验证：前端 **857 项测试通过**；Rust **1943 项单元测试＋4 项集成测试通过**，6 项需要真实账号/环境的测试保持忽略。生产界面构建通过，Windows release 库另外执行隔离烟测、后台跨进程重启测试及两款 Nano Banana 的本地模拟上游路由测试。图片路由测试验证请求模型、端点、鉴权和资产存储，不调用 Google/OpenAI/Seedream 付费接口。

实际账号的模型可用性仍取决于上游权限和额度。Gemini 图片支持不是 Imagen `predict`，OpenAI 图片预设使用 API Key 而不是 ChatGPT 登录令牌。macOS/Linux 安装包、真实账号 OAuth、付费生成及实际 OTools 宿主安装端到端验收未作为本次已验证结果。
