AI Switch · AI本地网关 `v0.1.5`。本次只调整账号池管理界面的工具栏与列表，继续提供 **Windows x64 / Linux x64 / macOS ARM64** 三个分平台安装包，每个包只包含该平台自己的 native 库。默认地址仍是 `http://127.0.0.1:29527`，从 `0.1.4` 升级不需要改客户端配置，也不涉及数据库迁移。

## 改进：账号来源筛选移到左侧

账号列表上方的筛选行原本把「批量名/账号筛选框 + provider 来源」整体靠右排列。现在改为两端对齐：

- **provider 来源**（通用 TAB 的来源 chip 行；图片/视频/音频 TAB 为来源下拉）移到最左。
- **批量名/账号筛选框**留在最右，`筛选：` 标签在它前面。

这样「我想过滤到哪个来源」和「我想过滤哪几个账号」分别在两端，视线不用来回找。同时收紧了该行与上方算力池行的间距（上内边距 `pt-2` → `pt-1`，纵向内边距相应调整），两行贴合更紧凑。

来源 chip 的溢出行为不变：宽度不够时放不下的 provider 收到「更多」下拉，窗口变宽后恢复行内显示并保持已选来源。

## 改进：列表/卡片切换收进刷新下拉

账号工具栏上原本常驻一组「账号展示模式」图标按钮（列表模式 / 卡片模式）。本版把它收进**刷新下拉菜单**，作为一个「展示模式」分组：

- 分组里是两个单选项（`列表模式` / `卡片模式`），当前模式带勾选标记。
- 选择后立即切换并关闭菜单；选择仍写入 `localStorage`（`ai-switch.account-list-layout`），刷新后保持。
- 工具栏上因此少一个常驻控件，切换动作也更靠近它影响的那张列表。

## 新增：账号列表表头与单个全选复选框

账号列表上方原本并排两个文字按钮「全选」「反选」。本版改为**列表表头**：

- 表头只放**一个复选框**，不再有文字按钮。它是整个「全选当前页」的控制：本页未全选时点击＝选中本页全部；本页已全选时点击＝清空本页选择。
- 只选中了本页一部分账号时，复选框显示**半选（indeterminate）**状态，一眼能看出「选了一部分」而不是「没选」。
- 列表布局下表头与各行的列网格对齐，复选框正落在各行的勾选列上方；卡片布局只保留贴左的复选框。

行为变化：原来的「反选」按钮去掉了。之前它是「本页已选的取消、未选的选上」；现在表头复选框覆盖的是「全选 ↔ 清空」，半选状态提示部分选中。如果需要保留「反选」语义，请告知，可以再加一个不带文字的图标按钮。

## 分平台安装包

市场仍为分平台包模式（`packageMode=1`）。Release 同时提供三个包，每个只包含**该平台自己的一个** native 库：

- `otools-ai-switch-0.1.5-windows.oplg`（Windows x64）
- `otools-ai-switch-0.1.5-linux.oplg`（Linux x64）
- `otools-ai-switch-0.1.5-macos.oplg`（macOS ARM64；Intel Mac 暂不提供）

OTools 客户端按当前平台优先下载对应包，下载失败才回退到不带后缀的 `otools-ai-switch-0.1.5.oplg`。CI 打包时强制校验每个平台包只含一个 native 库。macOS 目前只有 ARM64 构建。

## 安装与数据

在 OTools 插件管理中安装/更新对应平台的 `.oplg`，或使用市场自动分发。请使用附带的 `SHA256SUMS` 校验下载文件。

数据库仍保存在 `~/.otools/local/otools-ai-switch/ai-switch.db`，更新不改存储目录或历史 SQL 迁移。本次纯前端界面调整，native 行为未变，不涉及数据库迁移。
